# StockMind

Адаптивний сайт навчального стартапу з прогнозування попиту для ритейлу. Побудований на Next.js App Router і готовий до деплою на Vercel.

## Локальний запуск

```bash
npm install
npm run dev
```

Відкрийте [http://localhost:3000](http://localhost:3000).

## Production build

```bash
npm run build
npm start
```

## Деплой на Vercel

1. Завантажте проєкт у GitHub/GitLab/Bitbucket.
2. У Vercel натисніть **Add New → Project**.
3. Імпортуйте репозиторій. Vercel автоматично визначить Next.js.
4. Натисніть **Deploy** — сайт отримає безкоштовну адресу виду `назва-проєкту.vercel.app`.

Секрети або environment variables для цієї версії не потрібні.
